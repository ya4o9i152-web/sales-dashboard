# 案件8「AI搭載 売上分析ダッシュボード」サンプル素材

案件8に取り組む受講生が **実際に手を動かせるように** 用意した、架空アパレル EC「**LUMINA**」の売上 CSV です。

> ⚠️ すべて学習用のダミーデータです。実在のブランド・商品とは関係ありません。

## 何に使うか

このダッシュボードは「売上 CSV をアップロード → KPI 集計・グラフ化 → AI が分析コメント」する仕組みです。動作確認には **アップロードする売上データ** が必要です。この素材を使って、

1. **CSV パース + バリデーション**（必須カラムの取り込み・無効行の検出）
2. **3 大 KPI 集計**（売上 / 粗利 / リピート率）+ 前月比
3. **カテゴリ別・SKU トップ10** の可視化
4. **AI 分析コメント**（サマリー + アクション提案）

までを、本物の案件と同じ流れで体験できます。

## ファイル

| ファイル | 形式 | 内容 |
| --- | --- | --- |
| `case8-sales-sample.csv` | CSV | アパレル EC の売上明細 40 件（2025年9〜11月の3ヶ月分） |

### カラム仕様（Step2/3 の DB スキーマと一致）

`order_date, customer_id, product_name, category, sku, quantity, revenue, cost`

- 日付は `YYYY-MM-DD` 形式
- 文字コードは UTF-8
- カテゴリは「トップス / ボトムス / アウター / アクセサリー」の4種
- 顧客 ID は一部が複数月にまたがって購入（**リピート率の計算**に使えます）

### リピート率

- 総顧客数: 28人 / リピーター（2ヶ月以上で購入）: 8人 → **リピート率 28.6%**

## このデータの「読みどころ」（AI分析の題材）

11月にアウター（ウールコート・ダウンジャケット）が急増し、売上が前月比約1.8倍になっています。AI分析コメントが「**冬物アウターが牽引**」「**11月のアクション提案**」を正しく拾えるかが、分析の型（プロンプト設計）の腕の見せどころです。
